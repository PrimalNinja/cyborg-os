CyborgOS - build info
======================

Build number: YYYYMMDD-N
  YYYYMMDD is the UTC date the archive was built. N starts at 1 each day and is
  incremented by 1 on EVERY build, whether or not that build was taken (applied).
  The number counts builds, not releases.

Maintaining this file
  - On every build, add a NEW entry at the TOP of the history below (newest first).
  - The entry heading is the build number: today's date, with N one higher than
    the highest N already used for today (1 if today has no entry yet).
  - Under the heading, list that build's changes as dot points.
  - Do not edit or delete older entries - they are the history.

Packaging rule (what goes in the archive) - READ THIS BEFORE ZIPPING
  - Top folder is UPPERCASE: CYBORGOS.
  - INCLUDE all source AND all tooling: everything under src/, tools/ (and any
    dependencies such as node_modules if present), pi/, zxn/, docs/, itchio/,
    sjasmplus/, and the generated build/ (the built .CYB/.BIN/.COM, discs, next/
    and msx/ folders - what you get back after a build).
  - Card images: the .img files go in as their own .zip, one per image, under
    cards/ (cards/*.img.zip). Do not also duplicate card images inside build/.
  - EXCLUDE only scratch: test/out/, test/t/, any __pycache__/, and the VCS .git/.
  - When in doubt, keep it. Dropping a tracked file is the error to avoid.

20261106-1
----------
Rebuild on NTC BASIC 20261106-0206 (the Bug 1 fix: a far-called #asm keyword in a page now
switches the page in) + the C0 flat build restored to HighCode, two new hypervisor docs, 128K
dropped.
- NTC compiler bumped in the builder (tools/cosbuild/src/js ntc_compiler.js + ntc_lib.js) to the
  20261106-0206 build - the far-asm-keyword page-switch fix (and its Bug 2 stub fix). The
  lifecycle members (Loaded/Page/Unload/Local*) are excluded from the wrapper, so overlay classes
  are unaffected; CyborgOS uses them and all suites stay green.
- C0 (flat) build: cyborgosc0/Main.bas had been migrated off Option HighCode to Option Memory
  Paged, which left the whole-hypervisor-in-main image overrunning the ROM line (#A5F0 -> ~#B55D).
  Restored Option HighCode + Option Place Hyp, Ent under Option Deprecated (the window stays on the
  modern Option Memory Paged &H4000, &H4000). The flat C0 build is the ONLY real-world use of
  HighCode; it is CPC-only and deprecated, so it is gated behind Option Deprecated and documented
  as a C0 exception. C0 now fits: data ends at ntc_free #944C (~4.4K under #A5F0), the overflow
  fills #C000-#FFAF (15.9K of the 16K at #C000), ~81 bytes free there.
- New docs: docs/cyborgos-c0.md and docs/cyborgos-c2.md - the hypervisor's own memory models (the
  flat C0 build and the split C2 build), with ASCII maps, the C0-vs-C2 role split (C2 is the
  hypervisor; in the C2 model C0 is a block-1 resource surface: disc buffers, two screens, the copy
  engine, the far-call trampoline, 6128 Plus sprites, firmware, loadable-driver dispatch), and the
  block-1 test for what belongs where. (cyborgos-memory-model.md remains the SLOT model.)
- 128K dropped: src/bas/cyborgos128kb moved to deprecated/cyborgos128kb (kept for reference, not
  built - it was already out of the build layout); the stale build/dsk/cyborgos128k.dsk removed;
  README paths updated.
- build/ regenerated with the new compiler (CPC c0/c2 discs, Next, MSX). The C0 loader is named
  COSLOADC0.BIN again (the builder emits CYB_HIGH only for a HighCode build).
