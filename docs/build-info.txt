CyborgOS - build info
======================

Build number: YYYYMMDD-N
  YYYYMMDD is the UTC date the archive was built. N starts at 1 each day and is
  incremented by 1 on EVERY build, whether or not that build was taken (applied).
  The number counts builds, not releases.

Maintaining this file
  - On every build, add a NEW entry at the TOP of the history below (newest first).
  - The entry heading is the build number: today's date, with N one higher than
    the highest N already used for today (1 if today has no entry yet).
  - Under the heading, list that build's changes as dot points.
  - Do not edit or delete older entries - they are the history.

Packaging rule (what goes in the archive) - READ THIS BEFORE ZIPPING
  - Top folder is UPPERCASE: CYBORGOS.
  - INCLUDE all source AND all tooling: everything under src/, tools/ (and any
    dependencies such as node_modules if present), pi/, zxn/, docs/, itchio/,
    sjasmplus/, and the generated build/ (the built .CYB/.BIN/.COM, discs, next/
    and msx/ folders - what you get back after a build).
  - Card images: the .img files go in as their own .zip, one per image, under
    cards/ (cards/*.img.zip). Do not also duplicate card images inside build/.
  - EXCLUDE only scratch: test/out/, test/t/, any __pycache__/, and the VCS .git/.
  - When in doubt, keep it. Dropping a tracked file is the error to avoid.
