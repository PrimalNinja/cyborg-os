CyborgOS Builder

Open the CyborgOS folder - the one with src/ and tools/ in it (where you unzipped CyborgOS). Its build is tools/cosbuild/CyborgOS.layout.json.

Then Build: Run. It stops where sjasmplus has to run (it says which script, in build/stage); run it, then Run again - to the end. What it makes is in build/ (dsk/cos-disk1..7.dsk, next/...).

node (no browser): node tools/cosbuild/src/cli.js build
Part
The build is this layout: stages (sections) of steps (containers) of parts - drag them in from the palette on the left; double-click a part for its properties (Save Properties). Changes go into the layout's file.
The project: the files the layout's Imports part names, at their paths in the folder. A file changed here is written back to the folder (Chrome, Edge; else Download changed files).
File
CPC discs (.DSK - data format, 178K, 64 files)
New hard disc image (.img - WinAPE's IDE, UniDOS, a CF or SD card: FAT16 under 64MB, FAT32 from 64MB)
Into an image that is there (a card image, WinAPE's .ide, a dd of a card - FAT12/16/32, 8.3 names; files over ones of their name)
