CyborgOS - HELP name shows NAME.HLP (HELP DIR, HELP CD ...)                 [1]
Built in: RUN, CLS, QUIT. On the system drive Z (from the boot disc): FG,
PS, TOP, KILL, RESET, WAIT, MEM, DIR, CD, CV, HELP, COPY, ERA, TYPE,
RENAME, RAMDISC, MODE, MKDIR, RMDIR, DRIVE, CLAIMS. On the boot drive:
MOUNT, PAUSE, UNPAUSE, FLOPPY, NET, MON, YING, YANG, RAWYING, RAWYANG; the
decision services: RAT, MODEL, NEURAL, ASK, PROBE (their test drive), RATS,
WATCH; PET (a virtual pet); RATBOX (a box of rats); RVDU (remote displays);
Pluto: ENC, DEC, KEYMGR (encode / decode files, the key manager - HELP
PLUTO)

name [args]       runs that program (from Z, the slot's drive, the boot
drive)
RUN [slot] name [args]   the same, even when a command has that name;
                  with a slot: runs it there (RUN 2 CRUNCH)
FG slot           that slot to the front
KILL slot         stops its program
PAUSE, UNPAUSE slot   its program stopped where it is; going on again
RESET [slot]      that slot (or this one) as new
PS, TOP           the slots; with their speed
MEM               the memory: main RAM, the banks
DIR, DRIVE        files; the drives and devices
CV, CD            this slot's drive or device; a folder (UniDOS)
MOUNT dev letter  a device to a drive letter: MOUNT SD E (UniDOS)
-- more (space, Enter, Q) --_
